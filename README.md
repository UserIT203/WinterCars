# WinterProject

Unity-проект с зимними сценами: прогулочный облёт камерой заснеженного леса и песочница с машинами, между которыми игрок может пересаживаться на лету.

## Требования

- **Unity 6000.3.11f1** (Unity 6.3)
- **URP** 17.3.0
- **Input System** 1.19.0 (новый ввод, старый `Input` не используется)
- MCP for Unity подключён локальным пакетом: `com.coplaydev.unity-mcp` → `C:/Users/user/Desktop/unity-mcp-beta/MCPForUnity`. Если этой папки нет, зависимость нужно убрать из `Packages/manifest.json`, иначе проект не откроется.

## Сцены

| Сцена | Путь | Назначение |
|---|---|---|
| StartScene | `Assets/Dev/StartScene.unity` | Стартовое меню, кнопки перехода в остальные сцены |
| WinterForest | `Assets/Dev/WinterForest/_Scene/WinterForest.unity` | Зимний лес, автоматический облёт камеры по точкам маршрута |
| Cars | `Assets/Dev/Cars/_Scene/Cars.unity` | Дороги, машины на автопилоте, управляемая машина игрока |

Остальные сцены в `Assets/` — демо из импортированных ассет-паков (ARCADE Racing Car, Pandazole Nature, Realistic Hail Set и др.).

## Структура

Собственный код проекта лежит только в `Assets/Dev/` — всё прочее в `Assets/` это сторонние ассеты.

```
Assets/Dev/
├── SceneSwitch.cs                      # кнопка UI → загрузка сцены по имени
├── StartScene.unity
├── Cars/
│   ├── Scripts/
│   │   ├── Car.cs                      # машина: режим AI/игрок, пересадка по клику
│   │   ├── ICarMovement.cs             # общий контракт способа движения
│   │   ├── RoadNode.cs                 # узел дорожного графа со списком следующих узлов
│   │   ├── MovementType/
│   │   │   ├── MovementAI.cs           # езда по графу дорог, развороты в тупиках
│   │   │   └── PlayerMovement.cs       # ручное управление WASD
│   │   └── CameraFollow/
│   │       └── CarCameraFollow.cs      # камера за машиной игрока
│   ├── Material/
│   └── _Scene/
└── WinterForest/
    ├── Scripts/CameraFollow/
    │   └── CameraWaypointTour.cs       # облёт камеры по waypoint'ам
    ├── Prefabs/                        # деревья и стволы зимнего леса
    └── _Scene/
```

## Как это работает

### Машины (`Cars`)

- **Движение вынесено за компонент.** `Car` — это MonoBehaviour, который хранит настройки и каждый кадр дёргает `_movement.Move()`. Сама логика движения — обычные C#-классы `MovementAI` и `PlayerMovement` за интерфейсом `ICarMovement`; смена режима это просто пересоздание объекта движения.
- **Пересадка.** Клик по AI-машине (`IPointerClickHandler`, нужен коллайдер и `EventSystem` на сцене) переводит её под управление игрока, а прежняя машина игрока возвращается на автопилот и встаёт на ближайший `RoadNode`. Текущая машина игрока доступна статически: `Car.PlayerCar`.
- **Маршруты.** `RoadNode` хранит список следующих узлов; на развилке следующий выбирается случайно, но узлы строго позади отсекаются по направлению движения — машина не разворачивается посреди дороги. В тупике разворот разрешён и выполняется на месте с торможением.
- **Управление игрока:** `W`/`S` — газ и задний ход, `A`/`D` — руль. Руль работает только на ходу и зеркалится на заднем ходу; отпущенный газ — накат до остановки.
- **Камера** (`CarCameraFollow`) сама находит `Car.PlayerCar` и переключается на новую машину при пересадке. `_fallbackTarget` используется, только когда машины игрока нет.

### Облёт леса (`WinterForest`)

`CameraWaypointTour` проигрывает маршрут камеры по списку точек. Каждая точка задаётся либо `Transform`-целью в сцене (тогда позиция и поворот берутся с неё и обновляются каждый кадр), либо координатами вручную, и имеет своё время перелёта, доворота, стоянки и кривую сглаживания. Поддерживаются зацикливание, старт из текущего положения камеры и работа в unscaled-времени. Маршрут рисуется гизмо в сцене; в контекстном меню компонента есть команды добавления точки из текущего положения камеры.

События: `OnWaypointReached(int index)`, `OnTourFinished`.

## Запуск

1. Открыть проект в Unity 6000.3.11f1.
2. Открыть `Assets/Dev/StartScene.unity` и нажать Play — переходы в остальные сцены идут через кнопки.
3. Отдельные сцены можно запускать напрямую; для сборки все три сцены должны быть добавлены в Build Profiles → Scene List, иначе `SceneSwitch` не найдёт сцену по имени.
